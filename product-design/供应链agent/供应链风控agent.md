## 1. 产品概述

### 1.1 一句话定位

> 一款面向中小制造、贸易、电商、外贸企业的**主动式供应链风控 AI Agent**：7×24 风险扫描 + 交期预判 + 库存健康监控 + 供应商评级 + 交付风险推演 + 自动复盘沉淀。**替代供应链/PMC/采购人员 80% 的重复盯防、核对、复盘工作，不做基础数据录入，不替代业务决策。**

### 1.2 与市面产品的本质区别

| 现有方案 | 短板 | 本产品 |
| --- | --- | --- |
| 传统 ERP/SCM | 静态存档、被动记录，无预警、无推演、无复盘 | 主动式 Agent 风控闭环 |
| 通用 AI 问答 | 不懂业务数据、幻觉严重、无自动化 | 垂类规则库 + 业务数据联动 |
| 大厂供应链平台 | 大而全、重部署、高价，中小企业用不上 | 轻量化 SaaS、极速落地 |
| 轻量报表工具 | 只「看数据」不「管风险」 | 从统计升级为风控与避险 |

### 1.3 目标用户

- **企业类型**：中小制造、工贸一体、贸易公司、外贸企业、电商供应链团队
- **核心使用者**：采购、PMC、供应链专员、运营主管、企业老板
- **核心场景**：物料交期风控、库存健康管理、供应商评级、订单交付推演、异常复盘、知识沉淀

### 1.4 解决的核心痛点

1. **人工盯防成本高** —— Excel/微信/人工核对交期与库存，重复低效
2. **风险后置不可逆** —— 缺料、延期、积压、断供发现即事故：停产、违约、资金积压
3. **风险识别碎片化** —— 订单/物料/库存/供应商数据分散，无统一监控口径，看不到连锁风险
4. **供应商风控无体系** —— 无标准化履约评分，全凭经验，劣质供应商反复踩坑
5. **无常态化复盘** —— 问题无汇总、无归因、无沉淀，同类风险反复发生
6. **经验断层** —— 风控依赖老员工，人员流动导致业务能力断层

### 1.5 核心差异化

1. **原生 Agent 主动工作流**：自主定时扫描→分析→预警→报告，无需人工触发
2. **供应链垂类规则库**：交期/库存/供应商/推演专属规则 + AI 轻推理双校验，输出可溯源、可核验
3. **轻量化落地**：无需硬件、无需 ERP 改造，Excel 导入 / 标准 API / **主流 ERP 直连**多种接入方式
4. **全链路风控闭环**：监控→识别→预警→归因→推演→复盘→沉淀
5. **标准化 SaaS 订阅**：摒弃项目制重交付，可规模化复制

## 3. 整体架构

四层轻量化架构，无需自研大模型，依托业务数据 + 垂类规则引擎 + AI 轻推理构建壁垒。

```
┌─────────────────────────────────────────────┐
│  交互层：Web 管理后台（看板/报表/导出）·        │
│         移动端小程序（预警/任务/快捷处理）        │
├─────────────────────────────────────────────┤
│  Agent 层：交期风控 · 库存健康 · 供应商评级 ·    │
│           订单交付推演 · 自动复盘 · 知识问答      │
├─────────────────────────────────────────────┤
│  规则引擎层（核心壁垒）：交期四级判定 · 库存五级   │
│           标准 · 供应商四维评分 · 连锁推演 ·      │
│           输出校验（AI×规则双校验）               │
├─────────────────────────────────────────────┤
│  数据层：采购/库存/订单/供应商数据 ·             │
│  接入：Excel 导入 · 手动补录 · 标准 API ·        │
│        主流 ERP 直连（金蝶/用友/鼎捷等）          │
└─────────────────────────────────────────────┘
```

**Agent 统一工作流**（固定闭环，无人值守）：

> 数据采集 → 清洗校验 → 规则风险判定 → AI 智能归因推演 → 风险分级 → 预警推送 → 任务跟进 → 自动复盘 → 知识沉淀

### 3.1 数据层（分层接入，适配企业数字化水平）

> 现实情况：目标客群的数字化水平是光谱，不是只有「原始 Excel」。接入能力按三层设计，覆盖从低到高全谱系，**接入方式不影响风控能力**。

| 接入层级 | 适用企业 | 方式 |
| --- | --- | --- |
| L1 单据级 | Excel/微信管理的贸易、电商、小微工贸 | Excel 批量导入（模板化）+ 手动补录 + 定期增量导入 |
| L2 系统级 | 已有金蝶/用友/鼎捷等 ERP 或轻量进销存的制造企业 | **标准 API 直连 / 数据库只读同步**，自动增量更新——本层是主力客群，多数企业数据已在系统内，接入成本极低 |
| L3 数据成熟 | 有自建数据库/数据中台的中型企业 | 开放标准接口（Webhook/RESTful），字段映射配置 |

**数据安全设计（L2/L3 客群的关键信任门槛）：**

- 最小化采集：仅同步风控所需字段（交期/数量/供应商/状态），不碰财务金额明细，可配置字段白名单
- 只读权限：默认数据库只读接入，不回写客户系统
- 私有化选项：V1.2 提供私有化部署，适配数据敏感的大客户
- 全链路审计：数据访问日志企业主可查

### 3.2 规则引擎层（核心壁垒，防幻觉核心）

| 规则类别 | 内容 |
| --- | --- |
| 交期风险判定 | 按期 / 即将延期 / 大概率延期 / 已超期 四级判定逻辑 |
| 库存健康判定 | 缺货 / 临界缺货 / 超储 / 呆滞 / 健康 五级标准 |
| 供应商评级 | 履约率 / 质量合格率 / 响应速度 / 异常频次 四维评分 |
| 交付推演 | 缺料 → 工序滞后 → 订单延期连锁推演逻辑 |
| 输出校验 | 数据不足强制降级、结论可溯源、模糊风险明确标注 |
| 数据时效校验 | L1 周度导入等低频数据源，其相关结论强制标注「数据截止时间」并降级置信度 |

### 3.3 AI Agent 应用层（六大自动化智能体）

交期风控 / 库存健康 / 供应商评级 / 订单交付推演 / 自动复盘 / 知识问答——全部为主动式工作流 Agent，定时自主执行，无需人工干预。

## 4. 核心功能模块（V1.0 MVP）

### 模块 1：供应链总览智能看板（基础底座）

替代零散台账，全局风险可视化控制台。

- **全局汇总**：待到货物料、在途订单、库存总量、呆滞金额、高风险供应商数、待处理异常
- **风险分级可视化**：高危/中危/低危标签高亮，一键筛选
- **核心指标**：物料准时到货率、库存健康率、供应商优良率、订单按期交付率
- **快捷入口**：风险明细、当日复盘、预警任务

### 模块 2：物料交期智能风控 Agent（最高频刚需，P0）

解决「漏盯物料、隐性延期、临期爆雷、停工待料」。

- **每日全量扫描**：未到货采购单、在途物料、待补货物料
- **智能进度比对**：计划到货时间 × 当前进度 × 供应商历史履约周期 × 延期概率多维比对
- **四级风险识别**：即将到期 / 进度滞后 / 大概率延期 / 已超期
- **结构化输出**：风险等级、延期概率、影响工序、影响订单、建议动作（含成本对比，如「备选空运增量 ¥1.2 万 vs 停线损失 ¥8.4 万/周」）
- **决策点机制**：高风险项自动设定「到某时点无进展则升级处置」的决策提醒（推送给指定业务负责人）
- **分层预警**：提前 1/3/7 天分层推送，超期即时推送

### 模块 3：库存健康度监控 Agent（降本核心，P0）

解决「缺货停产」与「超储压资」双痛点。

- **动态监测**：全品类库存、消耗速率、采购周期、安全库存阈值
- **五级状态判定**：健康 / 临界缺货 / 即将缺货 / 超储积压 / 长期呆滞
- **资金损耗量化**：呆滞占用资金、超储成本、潜在缺货停产损失——**让老板看见损失的金额，是续费谈判的核心证据**
- **优化建议**：补货时机/数量、清库处理、库存结构优化
- **趋势复盘**：库存波动、积压/缺货频次、资金占用变化

### 模块 4：供应商智能风控评级 Agent（差异化壁垒，P1）

四维评分体系（0-100）：履约（准时率/延期时长/频次）、质量（不良率/返工/复发率）、配合（响应速度/资料配合/整改效率）、稳定（合作周期/波动/供货稳定性）。**评分随每笔交易动态更新**。

- **自动分级**：S（优质）/ A（良好）/ B（一般）/ C（高危）
- **高危预警**：高频延期、高不良率、低配合度自动标记
- **替换建议**：核心物料的高危供应商推送备选与备货建议（含切换过渡周期评估）
- **依赖度预警**：核心物料单一供应商采购占比超阈值（默认 60%）时独立预警，提示分单
- **月度复盘**：供应商表现、问题 TOP 排行、优化建议

### 模块 5：订单交付风险推演 Agent（老板核心刚需，P2——价值最大、数据依赖最重）

打通「客户订单 → 生产工单 → 物料供应」全链路，解决「交付心里没底」。

- **全链路关联**：自动绑定订单、生产计划、物料、到货进度
- **连锁推演**：物料延期/库存缺货 → 工序滞后 → 订单延期概率
- **影响链路可视化**：以「客户订单 → 生产工单 → 采购单 → 供应商」链路图呈现风险传导路径，风险节点高亮标注——让老板一眼看清「哪一环断了、断了影响谁」
- **交付风险清单**：高风险 / 大概率延期 / 可控风险订单每日明细
- **风险溯源**：定位风险来源（物料/供应商/库存/排产）
- **应急建议**：加急备货、催货、订单调整、备选替代

> **数据依赖说明**：推演精度依赖 BOM 与生产计划数据质量。BOM 不准是中小厂常态，故本模块置后：先以「订单 × 采购单 × 库存」的简化链路推演（不依赖完整 BOM），数据质量验证后再开放工序级精细推演。

### 模块 6：供应链全自动复盘 Agent（留存核心，P1）

日小结 / 周深度 / 月全局，固定模块：

1. **周期指标汇总**：到货率、交付率、库存健康率、供应商合格率
2. **核心风险 TOP**：物料延期 / 库存积压 / 高危供应商 / 交付爆雷排行
3. **根因复盘**：人为疏忽 / 供应商问题 / 计划失误 / 管控漏洞归因
4. **闭环汇总**：已解决异常、处理方案、落地效果
5. **预警回溯统计**：周期内预警有效率（预警后实际发生风险或干预产生止损的比例）、避免损失金额——**产品自证价值的核心数据，续费谈判直接引用**
6. **下期重点**：重点监控物料、重点跟进供应商、重点防控风险

### 模块 7：企业供应链知识库 Agent（轻资产赋能，P2）

- **文档智能解析**：采购制度、SOP、异常处理流程、合同条款、物料标准
- **案例自动沉淀**：异常处理完成即自动归档
- **现场答疑**：交期跟进、异常处理、库存管控、供应商追责
- **知识主动推送**：高频风险、新增异常对应推送处理标准与案例
- **防幻觉约束**：无企业数据/标准/案例支撑时如实反馈，不编造；所有答疑可溯源

## 5. 核心产品规则（壁垒核心）

### 5.1 零幻觉输出规则

1. **数据溯源**：所有风险判定、结论、建议绑定原始单据与业务规则
2. **模糊信息降级**：数据缺失、无法判定时明确标注不确定性，不输出无效结论
3. **双校验**：AI 推理结果必须经供应链垂类规则二次校验

### 5.2 业务严谨性规则

1. 所有分析、预判、建议均为**业务辅助参考**，不替代人工决策
2. 高危风险、资金损耗、交付违约结论强制标注风险提示
3. 数据、报告、记录永久留存可溯源，满足企业台账管理需求

### 5.3 Agent 自动化工作流规则

固定闭环流程（采集→清洗→判定→归因→分级→预警→跟进→复盘→沉淀），全程无人值守。

## 6. 用户核心流程

```
企业入驻 → 导入/直连业务数据（Excel / ERP API）→ 配置阈值与规则
        ↓
Agent 启动 7×24 自动值守 · 更新风险看板与指标
        ↓
捕捉交期/库存/供应商/交付异常 → 分级推送预警
        ↓
人工跟进闭环（催货/补货/沟通）→ 更新处理状态
        ↓
日/周自动复盘 → 案例归档 → 知识库沉淀
        ↓
员工知识库答疑 → 风控体系持续迭代
```

## 8. 商业化设计（SaaS 订阅体系）

| 版本 | 定价逻辑 | 能力范围 |
| --- | --- | --- |
| **免费试用版** | 免费 | 50 条物料数据、基础风险扫描、每日简易复盘、有限次问答——测评体验 |
| **基础标准版** | 按物料量/用户数订阅 | 全量交期风控、基础库存监控、简易供应商评分、日常预警、基础复盘——小微企业 |
| **企业高级版** | 订阅 + 阶梯 | 无数据量限制、全模块能力、订单深度推演、供应商完整评级、定制报表、多账号权限、专属售后、知识库全量导出——中小工厂/贸易公司 |

> **定价锚点**：呆滞库存资金占用（面板直接量化展示）、一次停工待料的损失、一次订单违约赔偿——三者任一都远超年订阅费。建议定价页内建「资金占用损失计算器」辅助转化。

## 9. 竞品差异化对比

| 竞品类型 | 核心短板 | 本产品优势 |
| --- | --- | --- |
| 传统 ERP/SCM 系统 | 静态存档、被动记录，无主动风控、无预警、无推演、无复盘 | 主动式 Agent 全自动风控：事前预判、事中预警、事后复盘 |
| 通用 AI 问答工具 | 无业务数据联动、不懂供应链场景、幻觉严重 | 垂类规则约束、真实业务数据联动、零幻觉、完整闭环 |
| 大厂供应链平台（金蝶云/用友/鼎捷生态） | 模块大而全、风控只是附属功能、中小企业为用不上的功能付费 | 风控单一垂类做深，轻量订阅，按需付费 |
| 钉钉/企微生态轻工具 | 表单+流程为主，无智能风控、无跨单据推演 | 规则引擎驱动的智能风控，非流程工具 |
| 传统报表工具 | 只统计展示，无风险识别、无归因、无预警 | 从「看数据」升级为「管风险、降损失」 |

## 10. 风险与规避

| 风险类型 | 具体风险 | 规避方案 |
| --- | --- | --- |
| 数据适配 | 企业数据不规范、单据零散、字段口径不一 | 三层接入（Excel/API/ERP 直连）+ 数据异常标注清洗 + 字段映射配置 |
| 数据信任 | 采购价、供应商名单属商业机密，企业顾虑外流 | 最小化采集、只读权限、字段白名单、访问审计、私有化选项 |
| AI 输出精度 | 纯模型推理业务偏差 | AI 轻推理 + 业务规则强校验，规则优先 |
| BOM 数据质量 | 订单推演依赖 BOM，中小厂 BOM 常不准 | 推演模块分期：先简化链路（订单×采购×库存），验证后开放工序级 |
| 使用门槛 | 中小企业员工数字化能力弱 | 极简操作、自动化为主人工为辅、简易指引 |
| 业务责任 | 预判被作为唯一决策依据 | 常驻「辅助工具」提示、高危结论强制风险提示、不替代人工决策 |
| SME 付费习惯 | 目标客群为「更好的 Excel」付费意愿待验证 | 免费→标准→高级分层试用转化路径；资金损耗量化让价值可看见 |

---

## 11. 赛道定位总结（克制版）

**优势面**：无金融合规红线、无硬件对接成本、ERP 直连使主力客群接入成本极低、交付/库存风险是企业真实且高频的痛点、闭环与知识沉淀构成数据资产壁垒。

**待验证面**（立项后需最先验证的三个假设）：
1. 中小企业为「风控自动化」付费的真实意愿与价格锚（vs 继续用 ERP 附带功能 + 微信）
2. 商业机密数据托管给第三方 SaaS 的信任门槛（决定 L2 客群转化率）
3. 简化链路推演的准确率是否足以支撑「老板刚需」的价值感知

## 附：MVP 落地优先级建议

| 优先级 | 模块 | 理由 |
| --- | --- | --- |
| P0 | 物料交期风控 + 库存健康监控 | 最高频刚需、纯规则引擎可实现（无 BOM 依赖）、价值可即时量化 |
| P1 | 供应商评级 + 自动复盘 | 差异化壁垒与留存功能，依赖 3-6 个月数据积累后效果显现 |
| P2 | 订单交付推演 + 知识库 | 价值最大但数据依赖最重/内容冷启动需时间，置后开放 |

> **落地建议**：
> 1. **接入优先做金蝶/用友直连**——主力客群数据已在 ERP 内，直连的部署体验（数小时 vs 数天）是转化关键，Excel 只作为兜底和补充
> 2. **种子客户选「数字化中等」的工厂**——已有 ERP 但风控靠人工的企业，痛点最清晰、接入最快、付费能力最强；纯 Excel 企业作为 L1 低价版覆盖
> 3. **与工业 Agent 的协同**——两者客群重叠（中小制造企业），若并行推进，供应链以更低验证成本先行，跑通后向工业 Agent 客户交叉销售；数据层可共享企业主档案与接入组件
> 4. **价值证明内建于产品**——「呆滞资金占用」「避免的停工损失」统计报表是续费谈判的核心证据，V1.0 就要有，不能等 V1.2
> 5. **原型演示路径**（配套 `供应链风控agent-prototype.html`）：M201 芯片超期诊断（五段式 + 影响链路可视化 + 决策点）→ 供应商视图看 C 级替换预警与依赖度 → 复盘看「避免损失 ¥52 万」与预警有效率 74% → 问答演示「不执行业务操作」的责任边界 → 切换恒通贸易看 L1 接入的时效降级标注——十分钟讲完「替人盯供应链 + 量化省钱 + 有责任边界」三个核心卖点
